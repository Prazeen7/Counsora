# Counsora – Study Abroad Counseling Platform

Counsora is a web-based study abroad counseling platform designed to help education counselors provide structured, destination-specific guidance to students during counseling sessions.

The platform centralizes essential information about study destinations, academic programs, educational institutions, documentation requirements, cost estimations, and study guides, making the counseling process more efficient and organized.

**Live Application:** https://counsora.vercel.app/

## Important Notes

- **Server Startup Delay:** The backend server is hosted on Render's free hosting service. Due to inactivity, the server may enter a sleep state. As a result, the first request may take some time to respond while the server starts up. Subsequent requests should generally respond faster.
- **Single Active Session:** The same user account cannot be logged in on multiple devices simultaneously. Only one active login session is permitted per account.
- **Role-Based Access:** The platform supports three user roles: Counselor, Admin, and Superadmin. Access to platform functionality is determined by the assigned user role.

## Key Features

### 1. Destination-Specific Information
Select a preferred study destination and explore relevant educational opportunities, requirements, and guidance specific to that country.

### 2. Academic Program Exploration
Browse academic programs and courses to help students identify suitable study options based on their educational background, interests, and career objectives.

### 3. Institution Exploration
Explore universities and educational institutions across different study destinations, allowing counselors to guide students in selecting appropriate institutions.

### 4. Documentation Requirements
Access information about the documents required for studying abroad, helping counselors explain application requirements and preparation processes to students.

### 5. Cost Estimation
Review estimated study-related expenses, including tuition fees and other associated costs, to support financial planning and informed decision-making.

### 6. Study Guide
Access structured study-abroad guidance to assist counselors in explaining essential processes, requirements, and considerations throughout the student's educational journey.

### 7. Role-Based User Management
The platform supports three distinct user types:

- **Counselor:** Uses the platform to explore study destinations, programs, institutions, documentation requirements, cost estimations, and study guides during student counseling sessions.
- **Admin:** An administrative user role with access to functionalities based on assigned permissions.
- **Superadmin:** A higher-level administrative role with access to functionalities based on assigned permissions.

### 8. Single-Device Login Restriction
The platform restricts simultaneous logins using the same account across multiple devices, supporting controlled account access and session management.

## Purpose

Counsora is developed specifically for education counselors and study-abroad consultancies to streamline the student counseling process.

By centralizing destination-specific educational information, the platform reduces the need to navigate multiple resources during counseling sessions and enables counselors to deliver more organized, consistent, and informative guidance.
